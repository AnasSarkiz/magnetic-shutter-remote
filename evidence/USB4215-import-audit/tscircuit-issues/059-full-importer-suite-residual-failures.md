# Full importer regression gate still has residual baseline failures

Status: **suspected** compatibility/test-expectation failures requiring triage. No confirmed new tscircuit bug is asserted from a failing test alone. Gate: **blocked**.

## Affected versions and component context

`easyeda` 0.0.364, R5 local source based on 140046d000238f3d6c8611989682efb2872f25a9, final isolated peers/versions in [manifest](../working-dependency-manifest.json). SVG 0.0.433 is newer than the importer's original test-driver range 0.0.408. Earlier R4/R5 local changes are retained. Qualification target: GCT USB4215-03-A/C37616412; its focused regression is passing, not among the failed cases. Other components here are existing library test inputs, not additional fitted board parts or approved substitutions.

## Reproduction, input files and exact command

From `toolchain/easyeda-converter`, run `bun test` with the locked local peer graph and public component/3D-model access. Inputs, tests and existing golden snapshots are in [fixed source archive](../source-bases/easyeda-converter-fixed.tar.gz), with the unchanged control in [base archive](../source-bases/easyeda-converter-base.tar.gz). The isolated installed graph is described by [REPRODUCE.md](../REPRODUCE.md) and fixture/bun.lock. Run the same command in toolchain/easyeda-baseline for the paired source control.

## Expected and actual

The complete suite should pass before claiming a generally validated importer release. Final corrected run:278 pass / 33 fail,311 tests,57 snapshots passed/3 failed. Paired unchanged-source control:237 pass / 72 fail,309 tests. All 33 failing names also fail the control; no new failing name in that pair. Earlier public-download/control results differ, so name parity does not prove identical root causes or waive assertions.

[Exact full log](../logs/importer-final-qualified-suite.log), [control log](../logs/baseline-final-qualified-suite.log), [comparison](../logs/suite-comparison-final-qualified.json) and [machine-readable cases/errors](../logs/unresolved-suite-failures.json). Snapshot differences, source expectations and renderer/resource errors remain preserved; no blanket snapshot update or tolerance change was performed.

## Root-cause facts and hypotheses

Confirmed: the failures are reproducible in retained runs and all final failing names appear in the control. The new USB4215 raw/CAM regression, 48 existing source-field/contour fixtures, seven declaration builds and locked fixture checks pass. Reviewed inline changes add only raw-source paste/mask fields/regions. The broader failure set was not fully triaged in this focused run. Hypotheses include inherited local-source/older expectation mismatches, SVG/3D driver drift and public-resource variation. These must be verified case by case; they are not reported as confirmed defects or automatically accepted warnings.

## Impact and remaining work

Blocks declaring the entire toolchain/upstream patch release fully regression-qualified. It does not invalidate the recorded independent USB4215 source-fidelity measurements, and it does not supply missing manufacturer/assembler approval. No patch to these residual tests or their source is offered. A maintainer must compare each failure against current documented behavior and authoritative fixture input before changing expectations or code. Broad frozen-board regression was not rerun. R5 remains NOT FOR FABRICATION; no R6.
